    Constant Summary

    BUFFER_SIZE = 256 * 1024

    Initial buffer size used in #read.

    CHUNK_SIZE = 1024 * 1024

    Maximum size of a chunk requested from the camera at once by #read and #write_to, the same as used by libgphoto2 itself for reading files in chunks (i.e. in its PTP driver). Larger chunks mean fewer round trips, while some cameras might not handle these too large.

    MAX_PREALLOCATED_SIZE = (64 * 1024) * 1024

    Maximum buffer size allocated upfront in #read, based on the file size reported by the camera, which might be bogus (i.e. 0xFFFFFFFF).

    PREVIEW_FILENAME = "capture_preview.jpg"

    Name of the preview files, used when the mime type of their data is unknown (otherwise named after it, i.e. capture_preview.ppm).

    UNKNOWN_MIME_TYPE = "unknown/unknown"

    The unknown mime type as specified by the libgphoto2.

    def save(path : Path | String = name) : Nil #

    Saves file #data at given path, defaulting to file #name in the current working directory.

    When path points to an existing directory (or ends with a path separator), the file is saved inside of it, under its #name.

    NOTE An existing file is overwritten only once the whole file has been downloaded, while a new one is written as the data is read from the camera (see #write_to) into a temporary file, which is renamed to path once done, or removed if that fails.

    def to_slice : Bytes #

    Returns a copy of file #data as Bytes.

    NOTE The data is copied, since the original buffer is owned by libgphoto2, and freed along with the file (see #close). Use #write_to or #save to avoid the copy.

    NOTE Raises OverflowError for files larger than Int32::MAX bytes, which Bytes can't hold; use #write_to or #save for those instead.


    [View source]
    def write_to(io : IO) : Nil #

    Writes file #data to the given io, without copying it first.

    Unless the data is at hand already (i.e. of previews, or after accessing #data), it's read from the camera in chunks, so that the whole file is never held in memory (i.e. for large videos). Camera drivers not supporting that get the whole file downloaded instead.

    file = camera.preview
file.write_to(STDOUT)
